def audit_page(url, html):
    soup = BeautifulSoup(html, "html.parser")
    title_tag = soup.find("title")
    title = title_tag.get_text(strip=True) if title_tag else ""
    meta = soup.find("meta", attrs={"name": "description"})
    canonical = soup.find("link", rel="canonical")
    types = []
    for script in soup.find_all("script", type="application/ld+json"):
        data = json.loads(script.string)
        items = data if isinstance(data, list) else [data]
        for item in items:
            types.append(str(item.get("@type", "?")))
    return {
        "url": url,
        "title": title,
        "title_length": len(title),
        "meta_description": meta.get("content", "") if meta else "",
        "h1_count": len(soup.find_all("h1")),
        "canonical": canonical.get("href", "") if canonical else "",
        "schema_types": ", ".join(types),
    }


audit = pd.DataFrame([audit_page(u, h) for u, h in PAGES.items()])

@@lesson How websites answer: HTTP status codes
@@text
When a browser or Googlebot asks a server for a URL, the server answers with a **status code**: a three-digit number that says what happened. You see these in Screaming Frog, in Search Console's page indexing report, and in every crawl script.

| Code | Name | What it means for SEO |
|---|---|---|
| **200** | OK | The page works. This is what you want for pages you want indexed. |
| **301** | Moved permanently | A permanent redirect. Google moves its signals to the new URL over time. Update internal links so they point straight to the new URL. |
| **302** | Found (temporary redirect) | "Moved for now." Google may keep the old URL in its index for longer. If the move is permanent, use 301. |
| **404** | Not found | The page doesn't exist. Fine for pages that never existed. A problem when good pages or backlinked URLs return it. |
| **410** | Gone | Removed on purpose. Google treats 404 and 410 almost the same: both drop out of the index over time. |
| **429** | Too many requests | You are crawling too fast. Slow down. |
| **5xx** | Server error (500, 502, 503...) | The server failed. If errors last, Google crawls less and pages can drop out of the index. 503 means "temporarily unavailable", the right code for planned maintenance. |

The first digit tells you the family: **2** = success, **3** = redirect, **4** = problem with the request (often a missing page), **5** = problem on the server.

@@lesson Fetching pages politely (requests in Colab)
@@text
In real life you get a page's HTML with the **requests** library. This part can't run in this course: browsers don't let one web page download other websites' HTML (a safety rule). So copy these cells into Google Colab.

**Be polite when you crawl.** You are using someone else's server:

- **Identify yourself** with a clear User-Agent, so the site owner knows who you are.
- **Wait between requests** with `time.sleep()`, 1–2 seconds or more for small sites.
- **Respect robots.txt**, and only crawl what you need.
- **Stop when you see 429 or many 5xx errors.** You may be overloading the site.
- Only crawl sites you own or have permission to audit. Read the site's terms first.

`example.com` below is a domain reserved for examples. Swap in a site you work on.

@@colab Fetch one page
@@code
import requests

url = "https://www.example.com/"
headers = {"User-Agent": "MyAgency-SEO-Audit/1.0 (+https://www.example.com/contact)"}   # change to your own details

response = requests.get(url, headers=headers, timeout=10)

print(response.status_code)                    # 200, 404, 503...
print(response.url)                            # the final URL, after any redirects
print(response.history)                        # redirects on the way, e.g. [<Response [301]>]
print(response.headers.get("content-type"))
html = response.text
print(html[:300])

@@colab A polite mini crawl
@@code
import time
import requests
import pandas as pd
from urllib.robotparser import RobotFileParser

SITE = "https://www.example.com"
USER_AGENT = "MyAgency-SEO-Audit/1.0 (+https://www.example.com/contact)"
urls = [SITE + "/", SITE + "/about", SITE + "/this-page-does-not-exist"]

rp = RobotFileParser(SITE + "/robots.txt")
rp.read()

rows = []
for url in urls:
    if not rp.can_fetch(USER_AGENT, url):
        rows.append({"url": url, "status": "blocked by robots.txt"})
        continue
    try:
        r = requests.get(url, headers={"User-Agent": USER_AGENT}, timeout=10)
        rows.append({"url": url, "status": r.status_code, "final_url": r.url, "redirects": len(r.history)})
    except requests.RequestException as e:
        rows.append({"url": url, "status": f"error: {e}"})
    time.sleep(2)   # be polite: wait between requests

results = pd.DataFrame(rows)
results

@@tip
Check AI crawlers for three things: a **timeout** on every request (without one, a script can hang forever), a **delay** between requests, and **error handling** that records failures instead of stopping or skipping silently. One more detail: Python's `robotparser` uses simple prefix matching and doesn't understand Google's `*` and `$` wildcards. For Google-accurate checks, ask for a library that supports them, such as `protego`.

@@lesson Reading HTML with BeautifulSoup
@@text
HTML is text with **tags** inside angle brackets: `<title>...</title>`, `<h1>...</h1>`, `<meta name="description" content="...">`. **BeautifulSoup** reads HTML so you can find tags without messy text searching.

The HTML of the Sweat & Co yoga mats page is loaded as `HTML`. Have a look first:

@@example The raw HTML
print(HTML[:700])

@@text
The main tools:

| Code | Finds |
|---|---|
| `soup.find("title")` | the first `<title>` tag, or `None` if there isn't one |
| `soup.find_all("h1")` | a **list** of every `<h1>` tag |
| `soup.find("meta", attrs={"name": "description"})` | the meta description tag |
| `tag.get_text(strip=True)` | the text inside a tag, without extra spaces |
| `tag["content"]` or `tag.get("content")` | an attribute's value |

`"html.parser"` is Python's built-in HTML reader. It needs no extra install.

@@example Title, meta description and H1
from bs4 import BeautifulSoup

soup = BeautifulSoup(HTML, "html.parser")

title = soup.find("title").get_text(strip=True)
print("Title:", title, f"({len(title)} chars)")

meta = soup.find("meta", attrs={"name": "description"})
print("Meta:", meta["content"] if meta else "MISSING")

h1s = soup.find_all("h1")
print(len(h1s), "H1:", [h.get_text(strip=True) for h in h1s])

@@lesson A mini on-page audit
@@text
Now put it all together. A function audits **one** page and returns a dictionary. A loop runs it on **every** page, and pandas turns the list of dictionaries into a table.

from bs4 import BeautifulSoup
import json
import pandas as pd

def audit_page(url, html):
    soup = BeautifulSoup(html, "html.parser")
    title_tag = soup.find("title")
    title = title_tag.get_text(strip=True) if title_tag else ""
    meta = soup.find("meta", attrs={"name": "description"})
    canonical = soup.find("link", rel="canonical")
    types = []
    for script in soup.find_all("script", type="application/ld+json"):
        data = json.loads(script.string)
        items = data if isinstance(data, list) else [data]   # JSON-LD can be one object or a list
        for item in items:
            types.append(str(item.get("@type", "?")))
    return {
        "url": url,
        "title": title,
        "title_length": len(title),
        "meta_description": meta.get("content", "") if meta else "",
        "h1_count": len(soup.find_all("h1")),
        "canonical": canonical.get("href", "") if canonical else "",
        "schema_types": ", ".join(types),
    }

rows = []
for url, html in PAGES.items():
    rows.append(audit_page(url, html))

audit = pd.DataFrame(rows)
audit[["url", "title_length", "h1_count", "schema_types"]]

@@text
Look at the pattern `x if condition else y`. It's a one-line if/else. `title_tag.get_text(strip=True) if title_tag else ""` means "use the title text if a title tag exists, otherwise use empty text". This is how the audit avoids crashing on missing tags.

@@solution
from bs4 import BeautifulSoup

def get_meta_description(html):
    soup = BeautifulSoup(html, "html.parser")
    tag = soup.find("meta", attrs={"name": "description"})
    if tag is None:
        return ""
    return tag.get("content", "")

results = {}
for url, html in PAGES.items():
    results[url] = get_meta_description(html)

for url, meta in results.items():
    print(len(meta), url)

@@explain
The blog page has no meta description, so `soup.find(...)` returned `None`, and `None["content"]` crashed the whole loop. The AI assumed every page has every tag. Real sites never do. Check for `None` and return a clear empty value, then flag it in your audit.

import time
import requests
import pandas as pd

USER_AGENT = "MyAgency-SEO-Audit/1.0 (+https://www.example.com/contact)"

@@tip
